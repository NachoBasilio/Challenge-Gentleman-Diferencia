# Servidores

Podemos tener servidores propios, los cuales se encarguen de manejar la lógica de negocio y la comunicación con el modelo de IA. Estos servidores pueden ser implementados en cualquier lenguaje de programación, y pueden estar alojados en cualquier lugar, ya sea en la nube o en un servidor local.

También podemos utilizar servidores MCP ya existentes, los cuales se encargan de manejar la lógica de negocio y la comunicación con el modelo de IA. Estos servidores pueden ser utilizados como una capa intermedia entre el host y el modelo de IA, lo cual puede ser beneficioso en proyectos grandes o complejos, ya que nos permite separar la lógica de negocio del host, lo cual facilita el mantenimiento y la evolución del código. Además, estos servidores MCP ya existentes pueden tener funcionalidades adicionales, como la gestión de usuarios, la autenticación, la autorización, etc. lo cual puede ser beneficioso en proyectos que requieran estas funcionalidades. Algunos ejemplos de servidores MCP ya existentes son:

- **MCP de Github**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con Github, como crear un repositorio, eliminarlo, etc.
- **MCP de Google Drive**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con Google Drive, como crear un archivo, eliminarlo, etc.
- **MCP de Trello**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con Trello, como crear una tarjeta, eliminarla, etc.
- **MCP de Slack**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con Slack, como enviar un mensaje, eliminarlo, etc.
- **MCP de Notion**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con Notion, como crear una página, eliminarla, etc.
- **MCP de Calendario**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con el calendario, como crear un evento, eliminarlo, etc.
- **MCP de Correo**: Este servidor MCP se encarga de manejar la lógica de negocio y la comunicación con el modelo de IA para realizar acciones relacionadas con el correo, como enviar un correo, eliminarlo, etc.

El SDK de MCP te permite crear un servidor personalizado de forma sencilla, ya que te proporciona una interfaz clara y definida para interactuar con el modelo de IA, lo cual puede ser beneficioso en proyectos grandes o complejos.
