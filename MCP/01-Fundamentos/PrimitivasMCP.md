# Primitivas

Un servidor MCP lo que puede hacer lo siguiente:

- Tener una serie de propmts, generando asi un estandar a la hora de realizar x tarea.
- Tener una serie de herramientas, las cuales pueden ser utilizadas por el modelo de IA para realizar acciones específicas.
- Tambien puede tener recursos, bases de datos, etc. los cuales pueden ser utilizados por el modelo de IA para realizar acciones específicas.
