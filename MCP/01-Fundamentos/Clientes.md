# Clientes

Los clientes a diferencia de los servidores son los que se encargan de conectarse con los servidores de MCP a partir de una configuruacion.

Claude desktop o Cursor son ejemplos de clientes, ya que se conectan a servidores de MCP para poder interactuar con el modelo de IA. Estos clientes pueden ser implementados en cualquier lenguaje de programación, y pueden estar alojados en cualquier lugar, ya sea en la nube o en un servidor local.

## Host personalizado

Si quieres crear un host personalizado, puedes utilizar el SDK de MCP para crear un host personalizado. El SDK de MCP te permite crear un host personalizado de forma sencilla, ya que te proporciona una interfaz clara y definida para interactuar con el modelo de IA, lo cual puede ser beneficioso en proyectos grandes o complejos. Además, el SDK de MCP te permite manejar la comunicación con el modelo de IA de forma sencilla, lo cual puede ser beneficioso en proyectos que requieran estas funcionalidades.

El cliente puede conseguir las herramientas que tenga el servidor, conectarse a varios serivodres simultaneamente, etc. Esto permite una mayor flexibilidad y escalabilidad, ya que podemos tener múltiples clientes MCP conectados a un mismo servidor MCP, y el servidor MCP puede manejar múltiples solicitudes simultáneamente. Además, esta arquitectura permite una mayor modularidad, ya que podemos separar la lógica de negocio del cliente MCP, lo cual facilita el mantenimiento y la evolución del código.
