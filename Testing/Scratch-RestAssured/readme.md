### Comando para crear proyecto con cmd:

mvn -U -B org.apache.maven.plugins:maven-archetype-plugin:3.3.1:generate -DarchetypeGroupId=org.apache.maven.archetypes -DarchetypeArtifactId=maven-archetype-quickstart -DarchetypeVersion=1.4 -DgroupId=com.ejemplo.api -DartifactId=restassured-demo -DinteractiveMode=false
